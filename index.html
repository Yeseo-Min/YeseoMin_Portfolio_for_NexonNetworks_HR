01
리서치 · 의사결정 지원
2022.10 – 2023.01

신입 온보딩 키트 벤치마킹 및 벤더 비교 리서치

배경

브랜드 대행사 인턴 시절, 신입 온보딩 키트 제작이 검토됐지만 사내에 벤치마킹 자료도 벤더 정보도 없어 실무진이 판단할 근거가 부족했습니다.

역할

담당자 없이 비어 있던 리서치를 자원해서 맡았습니다.

실행

토스·라인·콴다·넥슨·카카오페이·무신사·우아한형제들·크래프톤·사람인·삼성전자 등 10개 이상 기업 사례를 조사하고, 구성품을 개인용·업무용·기념용·애사심 4개 카테고리로 재구조화했습니다. 제작 벤더 4곳의 품목별 단가도 표로 비교 정리했습니다.

검토
완료
결과 · 러닝

실무진이 별도 조사 없이 바로 검토·의사결정할 수 있는 근거자료로 쓰였습니다.

원자료를 나열만 하지 않고 '필요/유용/추천' 우선순위까지 구조화해야 실무에 진짜 도움이 된다는 걸 배웠습니다.

직무 연결 — 복리후생·구성원 경험 제도를 설계할 때 타사 사례와 벤더 정보를 비교해 의사결정을 지원하는 인사 운영에 가장 직접 맞닿은 경험입니다.
02
AI 도구 · API 연동
2026.08 – 진행 중

아서(AUTHOR) — 폐쇄형 다이어리 SNS

배경

제한없이 모든 지인에게 근황을 알릴 수 밖에 없는 기존 SNS의 피로감을 해소하고 싶어 페이지 단위로만 선택 공유되는 '비밀일기+열쇠' 컨셉을 직접 구상했습니다.

역할

기획부터 개발까지 Claude Code와 함께 전 과정을 직접 주도했습니다.

실행

'내 기기에만 저장 vs 타인과 공유'라는 구조적 모순을 서버 암호화 저장 방식으로 직접 해결했습니다. OAuth 인증 흐름(Google Cloud Console↔Supabase)과 Supabase RLS(Row Level Security)는 생략하지 않고 이해될 때까지 질문하며 구현해냈고 공유취소 기능처럼 필요한 요구사항을 스스로 추가 제안했습니다.

구현
3/5
결과 · 러닝

설계한 MVP 5대 기능 중 3개(로그인, 개별 공유, 암호화 저장) 구현을 완료했습니다. 페이지 에디터는 아직 다듬는 중이고 캡처 방지 워터마크처럼 난도 높은 기능은 의도적으로 후순위에 두었습니다.

직무 연결 — JD가 요구하는 'AI 도구·API·MCP·Python 이해'를 실제 구현 경험으로 증명합니다. 인사 반복 업무를 API·AI로 자동화하는 AX 사례 발굴에 그대로 이어집니다.
03
AI 도구 · 실행력
2026.08 (약 2주)

옷 잘 챙겨입어 — 날씨 기반 옷차림 추천 웹서비스

배경

같은 기온이라도 사람마다 체감 옷차림이 다르다는 걸 체감하여 개인 데이터를 쌓아 유사 조건을 매칭 추천하는 서비스를 기획했습니다.

역할

MVP 범위와 기술스택을 직접 리서치해 결정하고 완성 후에는 직접 사용하며 QA했습니다.

실행

React·TypeScript·Vite / FastAPI·SQLite 등 웹 개발 표준 기술스택을 직접 조사해 명시했습니다. 1차 결과물이 예시 데이터로만 동작하는 걸 발견해 실제 날씨 데이터를 직접 찾아 연동했습니다.

2주
완성
결과 · 러닝

2주 만에 실사용 가능한 프로토타입을 완성해 모바일 링크로 실제 접속 가능한 상태까지 배포했습니다.

'상하의 미분리', '계절 소품 옵션 부재' 등 구체적 UX 결함을 QA로 직접 찾아 수정 요청했습니다. AI 결과물은 검증·보완해야 실제 쓸 수 있는 서비스가 된다는 걸 체득했습니다.

직무 연결 — 쉬운 프로젝트로 먼저 AI 협업 감각을 익힌 뒤 어려운 프로젝트로 돌아온 판단력은 새 자동화 도구를 도입할 때 작게 검증하고 확장하는 실무 태도로 이어집니다.

Python 기반 소년범죄 통계 재분석 (학부 논문)

역할

개인 단독 저자로 자료 수집부터 분석, 시각화까지 전 과정을 수행했습니다.

실행

대검찰청·경찰청·한국형사정책연구원의 소년범죄 통계를 연도별·분기별로 재구조화하고 Python으로 그래프 8종을 직접 시각화해 분석했습니다.

패턴
규명
결과 · 러닝

직무 연결 — ADsP 자격과 함께 대규모 근태·복무 데이터를 단순 합계로만 보지 않고 부서·시기별 이상치를 찾아내는 인사 데이터 분석 역량의 근거입니다.
